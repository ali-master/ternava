# مدل فارسی در Node.js و Bun

از ریشهٔ مخزن اجرا کنید:

```sh
bun install --cwd examples --frozen-lockfile
bun examples/node-bun/search.mjs 'خیلی دوستت دارم'
```

این مثال از نسخهٔ منتشرشدهٔ `@usex/ternava@0.2.0` و ورودی `@usex/ternava/runtime` استفاده می‌کند؛ به فایل‌های پایلوت محلی وابسته نیست. در Node.js هم قابل اجراست. پس از `await init()`، جست‌وجو روی دستگاه و بدون شبکه یا aliases انجام می‌شود.

مدل هنوز آزمایشی است و محدودیت‌های فارسی آن در README اصلی گزارش شده‌اند. این مثال به معنی آموزش جدید یا بهبود کیفیت مدل نیست.
