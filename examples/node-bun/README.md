# مدل فارسی در Node.js و Bun

از ریشهٔ مخزن اجرا کنید؛ روش ساخت پایلوت در [README اصلی](../../README.md#use-the-experimental-artifact) آمده است:

```sh
node examples/node-bun/search.mjs 'خیلی دوستت دارم'
bun examples/node-bun/search.mjs 'خیلی دوستت دارم'
```

این مثال همان فایل WASM پایلوت مرورگر را از دیسک می‌خواند و بدون شبکه یا aliases جست‌وجو می‌کند. بعد از `await init()`، توابع `embed`، `cosineSim` و `similar` همگام هستند. مسیر مدل نسبت به فایل اسکریپت حل می‌شود؛ به پوشهٔ جاری ترمینال وابسته نیست.

مدل هنوز آزمایشی است و محدودیت‌های فارسی آن در README اصلی گزارش شده‌اند. این مثال به معنی آموزش جدید یا بهبود کیفیت مدل نیست.
