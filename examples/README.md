# نمونه‌های فارسی ترنوا

رابط و دادهٔ نمونه‌ها فارسی شده‌اند. طراحی اصلی حفظ شده است: صفحهٔ مستندات با زمینهٔ تیره و صفحهٔ ایموجی با زمینهٔ روشن و تأکید نارنجی. هر دو صفحه راست‌به‌چپ‌اند و فونت متغیر **استعداد** را از فایل محلی بارگیری می‌کنند؛ بلوک‌های کد و نشانی‌ها چپ‌به‌راست باقی می‌مانند.

از ریشهٔ مخزن اجرا کنید:

```sh
python3 -m http.server 8000 --directory examples
```

- [گشت‌وگذار در تاریخ ایران](http://localhost:8000/docs-search/): ۱۲۰ روایت محاوره‌ای از ۶۰ مقالهٔ ویکی‌پدیا، از هخامنشیان تا پهلوی پیش از ۱۳۵۷.
- [جست‌وجوی ایموجی](http://localhost:8000/emoji-search/): ۷۰ ایموجی با نام و توضیح فارسی.
- [ادیسه در خط فرمان](odyssey-cli/README.md): ۲۸ گزیدهٔ بازنویسی‌شدهٔ فارسی.
- [پایلوت فارسی در Node.js و Bun](node-bun/README.md): اجرای همان WASM مرورگر، بدون شبکه و aliases.

این داده‌ها مجموعه‌های نمایشی‌اند، نه تاریخ جامع ایران یا ترجمهٔ کامل کتاب ادیسه. منابع، نسخهٔ مقاله‌ها و مجوز بازنویسی‌های تاریخی در پوشهٔ `docs-search` آمده‌اند.

**وضعیت مدل:** فایل‌های WASM همراه دو صفحهٔ مرورگر هنوز مدل‌های انگلیسی پیشین‌اند؛ CLI ادیسه اکنون پکیج محلی `@usex/ternava` با پایلوت دوزبانه را مصرف می‌کند. فارسی‌بودن رابط و داده به معنی تأیید کیفیت معنایی فارسی نیست. وزن‌های تصادفی آزمایش پایلوت در نمونه‌ها استفاده نشده‌اند. برای ارزیابی و آموزش مدل دوزبانه، [راهنمای پایلوت](../docs/persian-pilot.md) را ببینید. پس از تعویض مدل، تمام نمایه‌های برداری باید دوباره ساخته شوند.

## بررسی‌ها

```sh
node --test examples/tests/persian.test.mjs
node examples/emoji-search/build-index.mjs
node examples/odyssey-cli/prep.mjs
```

آزمون‌ها فارسی‌بودن مجموعه‌ها، پیوند نمایهٔ ایموجی با فایل WASM و متن منبع، برابری بردارها و رد نمایهٔ قدیمی ادیسه را بررسی می‌کنند. این‌ها آزمون کیفیت بازیابی نیستند.
